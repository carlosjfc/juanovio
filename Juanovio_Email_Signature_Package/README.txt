JUANOVIO INTERNATIONAL TRADING INC. — EMAIL SIGNATURE
======================================================
Email: carlos@juanovio.com

PACKAGE
- juanovio-email-logo.png: transparent PNG; email-compatible version of supplied logo.
- juanovio-signature-preview.html: opens locally, displays signature using an embedded image. Use it to preview the appearance; embedded images may be blocked by email providers.
- juanovio-signature-hosted.html: full HTML page using a publicly hosted logo.
- juanovio-signature-snippet.html: email-ready HTML snippet using a publicly hosted logo.

IMPORTANT — HOST THE LOGO
1. Upload juanovio-email-logo.png to your website at:
   Laravel project: public/images/juanovio-email-logo.png
2. Verify the image is publicly available at:
   https://juanovio.com/images/juanovio-email-logo.png
3. If you host it elsewhere, replace the image URL in the two hosted HTML files.
4. Do not leave the image on your personal computer: recipients need an HTTPS image URL.

INSTALLING IN GMAIL
1. Open juanovio-signature-hosted.html in your browser AFTER the image URL works.
2. Select the signature itself (image and text) and copy.
3. Gmail: Settings > See all settings > General > Signature > Create new.
4. Paste the rendered signature into the signature editor and assign it to new messages and replies as desired.
5. Save Changes, then send a test to yourself and check desktop/mobile.

NOTES
- Gmail's signature editor does not accept raw HTML code by direct pasting. Copy the rendered signature instead.
- If the logo fails to appear on paste, use the Gmail editor's Insert image control and select the hosted image URL.
- HTML snippet can be pasted into a signature manager or client that supports HTML source.
- Font fallback: Cinzel -> Georgia, Montserrat -> Arial. Many email clients do not load custom fonts.
- You may change 'Founder' if you prefer 'President', 'Managing Director', or another official title.
- A phone number is intentionally omitted because it was not supplied.
- URL is a proposed hosting path, not verified as currently online.
