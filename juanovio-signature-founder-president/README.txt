INSTALLING IN GMAIL
-------------------
1. Upload juanovio-email-logo.png to your Laravel site's public/images/ directory,
   so the expected image URL becomes:
   https://juanovio.com/images/juanovio-email-logo.png
2. Verify that the public URL actually loads the logo in a browser. This proposed
   URL has NOT been verified as already deployed.
3. Open juanovio-signature-hosted.html in a browser. Select and copy the VISIBLE
   signature (not the source HTML).
4. In Gmail: Settings > See all settings > General > Signature. Paste the
   rendered signature, select it as your email default, then Save Changes.
5. Send a test email to Gmail or Outlook and verify the logo and clickable links.
